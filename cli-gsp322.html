Como criar uma rede segura do Google Cloud

6 verificações100 pontos100% Cloud Shell
Versão alternativa O caminho recomendado é o guia pelo console. Use esta página só se preferir o terminal ou se travar em alguma tela do console.

Antes de começar

Abra o Cloud Shell e defina as variáveis com as três tags de rede do painel do lab:

export TAG_IAP=TAG-DO-SSH-PELO-IAP
export TAG_HTTP=TAG-DO-HTTP
export TAG_INTERNO=TAG-DO-SSH-INTERNO
export ZONE=$(gcloud compute instances list --filter="name=bastion" --format="value(zone.basename())")
export REGION=${ZONE%-*}
echo $ZONE $REGION

Se o echo mostrar a zona e a região, pode seguir.

1. Remover as regras abertas demais10 pontos

gcloud compute firewall-rules list --filter="network:acme-vpc"

Procure a regra com origem 0.0.0.0/0 liberando tudo (normalmente open-access) e apague:

gcloud compute firewall-rules delete open-access --quiet

2. Iniciar o bastion host10 pontos

gcloud compute instances start bastion --zone=$ZONE

3. SSH pelo IAP para o bastion20 pontos

gcloud compute firewall-rules create permitir-ssh-iap \
  --network=acme-vpc --direction=INGRESS --action=ALLOW \
  --rules=tcp:22 --source-ranges=35.235.240.0/20 \
  --target-tags=$TAG_IAP

gcloud compute instances add-tags bastion --tags=$TAG_IAP --zone=$ZONE

4. HTTP público para o juice-shop20 pontos

gcloud compute firewall-rules create permitir-http \
  --network=acme-vpc --direction=INGRESS --action=ALLOW \
  --rules=tcp:80 --source-ranges=0.0.0.0/0 \
  --target-tags=$TAG_HTTP

gcloud compute instances add-tags juice-shop --tags=$TAG_HTTP --zone=$ZONE

5. SSH interno: do bastion para o juice-shop20 pontos

export MGMT=$(gcloud compute networks subnets describe acme-mgmt-subnet \
  --region=$REGION --format="value(ipCidrRange)")
echo $MGMT

gcloud compute firewall-rules create permitir-ssh-interno \
  --network=acme-vpc --direction=INGRESS --action=ALLOW \
  --rules=tcp:22 --source-ranges=$MGMT \
  --target-tags=$TAG_INTERNO

gcloud compute instances add-tags juice-shop --tags=$TAG_INTERNO --zone=$ZONE

6. Conectar ao juice-shop pelo bastion20 pontos

Entre no bastion pelo IAP:

gcloud compute ssh bastion --zone=$ZONE --tunnel-through-iap

Responda Y e aperte Enter nas perguntas da chave. Já dentro do bastion, rode (troque ZONA pela zona do lab):

gcloud compute ssh juice-shop --internal-ip --zone=ZONA

Quando o prompt mudar para juice-shop, volte ao lab e verifique o progresso.

Erros comuns
  • Variáveis vazias: se abrir um novo Cloud Shell, rode os export de novo.
  • Apagar regras que não são abertas demais: apague só a de origem 0.0.0.0/0 que libera tudo.
Versão alternativa por linha de comando. Siga sempre o roteiro do laboratório: os nomes, a região e a zona mostrados no painel do lab têm prioridade sobre qualquer exemplo desta página.
