🔒 GSP322 – Como criar uma rede segura do Google Cloud

Selo de habilidade: Como criar uma rede segura do Google Cloud

6 verificações100 pontosFirewall da VPCTags de redeIAPBastion hostquase 100% console

Antes de começar

Regras de ouro
  • Abra o lab em janela anônima e use só o usuário e a senha do laboratório.
  • Os valores em amarelo (nomes, região e zona) mudam a cada execução: copie do painel do lab, à esquerda do roteiro.
  • Faça pelo console. Use comandos apenas onde esta página indicar, e sempre no Cloud Shell do projeto do lab.
  • Ao final de cada tarefa, clique em Verificar meu progresso. Se não passar, leia a mensagem, corrija e verifique de novo.
  • Não clique em Terminar o laboratório antes de todas as tarefas estarem verificadas.

Cenário: site juice-shop do Jeferson. No painel do lab, anote as três TAGS DE REDE: a do SSH pelo IAP, a do HTTP e a do SSH interno.

Objetivo final da segurança
  • O bastion host não tem IP público e só recebe SSH vindo do IAP.
  • O juice-shop só recebe SSH vindo do bastion (sub-rede acme-mgmt-subnet).
  • Só o HTTP (porta 80) do juice-shop fica aberto ao público.

1. Remover as regras abertas demais10 pontos

  1. Menu › Rede VPC › Firewall.
  2. Procure regras com origem 0.0.0.0/0 liberando tudo (por exemplo, "open-access" ou todas as portas).
  3. Marque a regra e clique em Excluir. Deixe as regras que não são excessivamente abertas.

2. Iniciar o bastion host10 pontos

  1. Menu › Compute Engine › Instâncias de VM.
  2. Marque a VM do bastion (está parada) e clique em Iniciar/Retomar.

3. SSH pelo IAP para o bastion20 pontos

  1. Rede VPC › Firewall › Criar regra de firewall.
  2. Rede: a VPC do lab (a mesma das VMs) · Entrada · Permitir.
  3. Tags de destino: TAG SSH IAP.
  4. Intervalo IPv4 de origem: 35.235.240.0/20 (faixa do IAP) · TCP 22.
  5. Adicione a tag na VM: Compute Engine › Instâncias de VM › bastion › Editar › Tags de rede › TAG SSH IAP › Salvar.

4. HTTP público para o juice-shop20 pontos

  1. Nova regra de firewall: Entrada · Permitir · Tags de destino: TAG HTTP.
  2. Origem: 0.0.0.0/0 · TCP 80.
  3. Adicione a tag TAG HTTP na VM juice-shop (Editar › Tags de rede).

5. SSH interno: do bastion para o juice-shop20 pontos

  1. Descubra o intervalo da sub-rede: Rede VPC › Redes VPC › acme-vpc › Sub-redes › anote o intervalo de acme-mgmt-subnet.
  2. Nova regra: Entrada · Permitir · Tags de destino: TAG SSH INTERNO.
  3. Origem: o intervalo da acme-mgmt-subnet · TCP 22.
  4. Adicione a tag TAG SSH INTERNO na VM juice-shop.

6. Conectar ao juice-shop pelo bastion20 pontos

  1. Em Instâncias de VM, clique em SSH na linha do bastion (a conexão passa pelo IAP).
  2. Anote o IP interno do juice-shop na lista de VMs.
Por comando (dentro da janela SSH do bastion) Esta é a única parte que exige comando, porque a conexão sai de dentro do bastion: 
ssh IP-INTERNO-DO-JUICE-SHOP
Se pedir confirmação, digite yes. Ao conectar, volte ao lab e verifique o progresso.
Erros comuns
  • Criar a regra na rede errada (default em vez da VPC do lab).
  • Criar a regra mas esquecer de colocar a tag na VM.
  • Usar 0.0.0.0/0 nas regras de SSH: é marcado como permissão excessiva.
Estratégia de resolução preparada para a turma. Siga sempre o roteiro do laboratório: os nomes, a região e a zona mostrados no painel do lab têm prioridade sobre qualquer exemplo desta página.
