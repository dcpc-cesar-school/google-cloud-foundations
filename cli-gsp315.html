Como configurar um ambiente de desenvolvimento de apps no Google Cloud

4 tarefas100 pontos100% Cloud Shell
Versão alternativa O caminho recomendado é o guia pelo console. Use esta página só se preferir o terminal ou se travar em alguma tela do console.

Antes de começar

Abra o Cloud Shell (ícone >_ no topo do console) e defina as variáveis com os valores do painel do lab:

export BUCKET=NOME-DO-BUCKET
export TOPIC=NOME-DO-TOPICO
export FUNCTION=NOME-DA-FUNCAO
export REGION=REGIAO
export USER2=EMAIL-DO-USUARIO-2
export PROJECT_ID=$(gcloud config get-value project)

Ative as APIs usadas pelo lab:

gcloud services enable run.googleapis.com cloudfunctions.googleapis.com \
  cloudbuild.googleapis.com artifactregistry.googleapis.com \
  eventarc.googleapis.com pubsub.googleapis.com logging.googleapis.com

Tarefa 1: criar o bucket25 pontos

gcloud storage buckets create gs://$BUCKET --location=$REGION

Tarefa 2: criar o tópico do Pub/Sub25 pontos

gcloud pubsub topics create $TOPIC

Tarefa 3: criar a função que gera miniaturas30 pontos

1. Permissão para o Cloud Storage publicar eventos

SA_GCS=$(gcloud storage service-agent --project=$PROJECT_ID)
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member=serviceAccount:$SA_GCS --role=roles/pubsub.publisher

2. Criar os arquivos da função

mkdir -p ~/miniatura && cd ~/miniatura
nano index.js

Cole o código do index.js do roteiro (já vem com o nome da função e do tópico). Salve com Ctrl+O, Enter e saia com Ctrl+X. Repita para o package.json:

nano package.json

3. Implantar

gcloud functions deploy $FUNCTION \
  --gen2 --runtime=nodejs22 --region=$REGION \
  --source=. --entry-point=$FUNCTION \
  --trigger-location=$REGION \
  --trigger-event-filters="type=google.cloud.storage.object.v1.finalized" \
  --trigger-event-filters="bucket=$BUCKET" \
  --quiet

Se der erro de permissão do Eventarc, aguarde 2 a 3 minutos e rode o mesmo comando de novo.

4. Testar

curl -o map.jpg LINK-DA-IMAGEM-DO-ROTEIRO
gcloud storage cp map.jpg gs://$BUCKET
gcloud storage ls gs://$BUCKET

Em alguns segundos aparece o arquivo map_64x64_thumbnail.jpg.

Tarefa 4: remover o engenheiro anterior20 pontos

gcloud projects remove-iam-policy-binding $PROJECT_ID \
  --member=user:$USER2 --role=roles/viewer
Cuidado Confira que USER2 é o e-mail do Usuário 2, e não o seu.
