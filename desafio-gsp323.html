🎯 Cenário e objetivo clique para abrir
Você é engenheiro de dados júnior da Jooli Inc. e vai mostrar o que aprendeu em quatro tarefas:
  • Dataflow: carregar um CSV do Cloud Storage para uma tabela do BigQuery;
  • Spark (Dataproc): rodar um job de exemplo (PageRank) num cluster;
  • Speech-to-Text: transcrever um áudio e salvar o resultado no Cloud Storage;
  • Natural Language: analisar um texto e salvar o resultado no Cloud Storage.
Onde o console não basta Tarefa 2: as instruções do lab exigem um comando hdfs dentro do cluster. Tarefas 3 e 4: as APIs não têm tela de uso no console; são chamadas por comando no Cloud Shell, e o resultado é enviado ao bucket.

Tarefa 1: job simples no Dataflow25 pontos

Criar o dataset e a tabela do BigQuery

  1. Menu de navegação (☰) › BigQuery › Studio.
  2. No painel Explorer, ao lado do ID do projeto, clique em ⋮ › Create dataset.
  3. Dataset ID: BigQuery Dataset Name. Deixe o resto como está.
  4. Clique em Create dataset.
  5. Ao lado do dataset BigQuery Dataset Name, clique em ⋮ › Create table.
  6. Table: Output Table Name.
  7. Schema: siga a dica das instruções do lab (clique em "Clique aqui para ver uma dica", logo abaixo de "Criar um bucket").
  8. Clique em Create table.

Criar o bucket

  1. Menu de navegação (☰) › Cloud Storage › Buckets e clique em Create.
  2. Name your bucket: Cloud Storage Bucket Name. Deixe o resto como está.
  3. Clique em Create. Se aparecer o aviso Public access will be prevented, clique em Confirm.

Criar o job do Dataflow

  1. Menu de navegação (☰) › View all products › Analytics › Dataflow › Jobs e clique em Create job from template.
  2. Job name: um nome à sua escolha, por exemplo lab-dataflow.
  3. Regional endpoint: selecione a opção Region.
  4. Dataflow template: em Process Data in Bulk (batch), selecione a opção Text Files on Cloud Storage to BigQuery.
  5. Preencha os campos com os valores da tabela das instruções do lab:
    • Cloud Storage Input File(s): gs://spls/gsp323/lab.csv
    • Cloud Storage location of your BigQuery schema file: gs://spls/gsp323/lab.schema
    • BigQuery output table: Output Table Name
    • Temporary directory for BigQuery loading process: Temporary BigQuery Directory
    • Temporary location: Temporary Location
  6. Abra Optional parameters:
    • JavaScript UDF path in Cloud Storage: gs://spls/gsp323/lab.js
    • JavaScript UDF name: transform
    • Machine type: desmarque Use default machine type e selecione a opção e2-standard-2.
  7. Clique em Run job. Espere o status mudar para Succeeded (leva alguns minutos).

Volte às instruções do lab no Google Skills e clique em Verificar meu progresso da tarefa 1.

Tarefa 2: job simples do Spark25 pontos

Criar o cluster

  1. Menu de navegação (☰) › View all products › Analytics › Managed Service for Spark (Dataproc) › Clusters e clique em Create cluster › Cluster on Compute Engine › Create.
  2. Region: selecione a opção Region.
  3. Em Configure nodes:
    • Manager node: Series selecione a opção E2 · Machine type selecione a opção e2-standard-2 · Primary disk type Balanced persistent disk · Primary disk size 100 GB;
    • Worker nodes: Series E2 · Machine type e2-standard-2 · Number of worker nodes 2 · Primary disk type Balanced persistent disk.
  4. Em Customize cluster, desmarque Configure all instances to have only internal IP addresses.
  5. Clique em Create. Espere o status Running.

Copiar o arquivo para o HDFS

  1. Menu de navegação (☰) › Compute Engine › VM instances.
  2. Na linha do nó administrador (nome terminado em -m), clique em SSH. Se pedir, clique em Authorize.
Por comando (as instruções do lab exigem) Na janela SSH do nó -m, rode: 
hdfs dfs -cp gs://spls/gsp323/data.txt /data.txt

Enviar o job

  1. Volte a Managed Service for Spark (Dataproc) › Clusters, clique no nome do cluster e em Submit job.
  2. Job type: selecione a opção Spark.
  3. Main class or jar: org.apache.spark.examples.SparkPageRank
  4. Jar files: file:///usr/lib/spark/examples/jars/spark-examples.jar (tecle Enter)
  5. Arguments: /data.txt (tecle Enter)
  6. Max restarts per hour: 1
  7. Clique em Submit. Espere o status Succeeded.

Volte às instruções do lab no Google Skills e clique em Verificar meu progresso da tarefa 2.

Tarefa 3: API Speech-to-Text25 pontos

Criar a chave de API

  1. Menu de navegação (☰) › APIs & Services › Credentials.
  2. Clique em Create credentials › API key.
  3. Copie a chave que aparece e clique em Close.
Por comando (Cloud Shell) No topo do console, clique em Activate Cloud Shell (ícone >_) e em Continue. Rode os blocos um de cada vez, esperando cada um terminar.

1. Guardar a chave de API:

export API_KEY=SUA_CHAVE

2. Criar o arquivo da requisição:

cat > request.json <<EOF
{"config": {"encoding": "FLAC", "languageCode": "en-US"},
 "audio": {"uri": "gs://spls/gsp323/task3.flac"}}
EOF

3. Chamar a API e salvar o resultado:

curl -s -X POST -H "Content-Type: application/json" --data-binary @request.json \
 "https://speech.googleapis.com/v1/speech:recognize?key=$API_KEY" > result.json

4. Enviar o resultado ao bucket:

gcloud storage cp result.json Cloud Speech Location
O arquivo .json é enviado com Content-Type application/json, como as instruções do lab pedem.

Volte às instruções do lab no Google Skills e clique em Verificar meu progresso da tarefa 3.

Tarefa 4: API Natural Language25 pontos

Por comando (Cloud Shell) Rode os blocos um de cada vez. Se o Cloud Shell perguntar se quer ativar a API, digite y e tecle Enter.

1. Analisar o texto sobre Odin:

gcloud ml language analyze-entities --content="Old Norse texts portray Odin as one-eyed and long-bearded, frequently wielding a spear named Gungnir and wearing a cloak and a broad hat." > result.json

2. Enviar o resultado ao bucket:

gcloud storage cp result.json Cloud Natural Language Location

⚠️ Erros comuns clique para abrir
  • Verificar o progresso antes de o job terminar: Dataflow e Spark levam alguns minutos. Espere o status Succeeded.
  • Esquecer o comando hdfs antes do job do Spark: o job falha por não achar /data.txt.
  • Criar o job ou o cluster em outra região: use sempre a Region do painel.
  • Enviar o resultado para outro caminho: use exatamente Cloud Speech Location e Cloud Natural Language Location.
  • Mudar o texto sobre Odin: copie o comando inteiro desta página ou das instruções do lab.
  • Nomes de botões diferentes dos desta página: a tradução automática do navegador está ligada. Veja "Antes de começar".
